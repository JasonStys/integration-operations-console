# Security policy

This is a local demonstration, not an internet-ready identity or secrets platform. The `X-Demo-Role`
header is intentionally educational and must not be treated as authentication.

Please report suspected vulnerabilities privately through GitHub's security-advisory feature. Do
not include secrets, personal information, or exploit traffic against systems you do not own.

Supported code is the current `main` branch. Dependency updates are monitored weekly and CodeQL
scans Java and TypeScript. See [Security model](docs/security.md) for trust boundaries and production
hardening work.
